Twenty short films walk the same path as these docs, in viewing order: what
Keelson is, chat and projects, workflows, what the harness keeps, and the ribs.
Each one runs for about two minutes, shows real runs on a real machine, and
explains what a piece is, why it exists, and how it works. Every docs page a film
covers carries it at the top, so you can also watch one where you are reading.
